# Keyboard shortcuts

## Main window

| Key | Action |
|---|---|
| `Ctrl`+`Tab` / `Ctrl`+`Shift`+`Tab` | Next / previous main tab |
| `Ctrl`+`` ` `` | Next sub-tab within active main tab |
| `Ctrl`+`D` | Download Settings |
| `Ctrl`+`U` | Upload Settings |
| `Ctrl`+`R` | Reset Settings |

## Firmware Editor

| Key | Action |
|---|---|
| `Ctrl`+`Tab` / `Ctrl`+`Shift`+`Tab` | Next / previous editor tab |
| `Ctrl`+`` ` `` | Next editor tab |
| `Ctrl`+`O` | Open firmware file |
| `Ctrl`+`D` | Download FW (stock build) |
| `Ctrl`+`F` | Flash to device |

## Device Monitor

| Key | Action |
|---|---|
| `Ctrl`+`P` | Pause / Resume |
| `Ctrl`+`F` | Toggle autofire |
| `Ctrl`+`S` | Screenshot |
| `Space` | Pause / Resume |
| `Esc` | Close screenshot modal |

Keys are ignored while typing in an input/textarea/select (except `Ctrl` combos
which also work while a field has focus in the Firmware Editor).

## 3. Reset Handler

**Address:** `0x00001658` (Thumb entry `0x00001659` in vector table).  
**Role:** unlock protected registers, enable FPU coprocessor, hand off to `__main`.

```text
0x00001658  ldr r0, [0x0000168c]   ; r0 = 0x40000100 (REGWRPROT)
0x0000165a  mov.w r1, #0x59        ; unlock sequence byte 1
0x0000165e  str r1, [r0]           ; write 0x59 to REGWRPROT
0x00001660  mov.w r1, #0x16        ; unlock sequence byte 2
0x00001664  str r1, [r0]
0x00001666  mov.w r1, #0x88        ; unlock sequence byte 3
0x0000166a  str r1, [r0]
0x0000166c  ldr r2, [0x00001690]   ; r2 = 0x40000024 (some protected reg)
0x0000166e  movw r1, #0x5aa5       ; unlock key
0x00001672  str r1, [r2]
0x00001674  ldr r2, [0x00001694]   ; r2 = 0x40000200
0x00001676  ldr r1, [r2]
0x00001678  bic r1, r1, #0x1000    ; clear bit 12
0x0000167c  str r1, [r2]
0x0000167e  movs r1, #0x0
0x00001680  str r1, [r0]           ; re-lock REGWRPROT
0x00001682  ldr r0, [0x00001698]   ; r0 = 0x000016a1 (SystemInit entry)
0x00001684  blx r0                 ; call SystemInit
0x00001686  ldr r0, [0x0000169c]   ; r0 = 0x000016b3 (__main entry)
0x00001688  bx r0                  ; tail-call __main
```

## 4. SystemInit

**Address:** `0x000016a0` (Thumb entry `0x000016a1`).  
**Role:** enable CP10/CP11 coprocessor access (FPU) by writing `0x00f00000` to `CPACR` (`0xe000ed88`).

```text
0x000016a0  ldr r0, [0x000016ac]   ; r0 = 0xe000ed88 (CPACR)
0x000016a2  ldr r1, [r0]
0x000016a4  orr r1, r1, #0xf00000  ; set CP10/CP11 full access
0x000016a8  str r1, [r0]
0x000016aa  bx lr
```

## 5. __main (C runtime startup)

**Address:** `0x000016b2` (Thumb entry `0x000016b3`).  
**Role:** reload SP, copy `.data` from flash, zero `.bss`, then call `main`.

The data init table is at `0x0001c774`–`0x0001c78b` (three 12-byte entries):

```text
Entry 0: src=0x0001c794, dest=0x20000000, len=0x00000058  ; copy .data
Entry 1: src=0x20000058, dest=0x20000058, len=0x00003168  ; zero .bss
Entry 2: src=0x00000000, dest=0x00000000, len=0x00000000  ; terminator
```

After init, `__main` branches to `main` at `0x0001834c` (Thumb entry `0x0001834d`).

## 6. main() and the UI Loop

**Address:** `0x0001834c` (Thumb entry `0x0001834d`).  
**Role:** peripheral / subsystem init, then run the screen dispatcher forever.

Key early calls (in order):

| Call | Target | Deduced Role |
|------|--------|--------------|
| `bl 0x00017474` | `FUN_00017474` | Clock / PLL init |
| `bl 0x000176d0` | `FUN_000176d0` | GPIO / port init |
| `bl 0x000175a0` | `FUN_000175a0` | ADC / analog init |
| `bl 0x00006678` | `FUN_00006678` | HID / USB init (uses dataflash byte at `0x2000001d`) |
| `bl 0x00006b94` | `FUN_00006b94` | Display / SSD1306 init |
| `bl 0x000133e0` | `FUN_000133e0` | Timer / systick init |
| `bl 0x000133cc` | `FUN_000133cc` | Interrupt enable |
| `bl 0x00016c64` | `FUN_00016c64` | Dataflash load / settings init |

After init, `main` enters one of two loops depending on a cold-boot flag at `0x20000058` (first `.bss` word):

- **Cold boot / normal runtime:** `bl 0x0000d684` (screen dispatcher) in a tight loop, polling a wake flag at `0x20002c30`.
- **Charge / low-power path:** alternate dispatcher loop with a different state byte (`0x1b`).

The screen dispatcher `FUN_0000d684` is documented in `resources/re/af_190602-dispatcher-analy.md`.
